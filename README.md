## 🔬 Core System Specifications

* **Stage 1 (Gatekeeper):** Fast Line-Rate XGBoost ($<0.5$ ms Latency)
* **Stage 2 (Inspector):** 1D-CNN with Multi-Head Self-Attention ($<1.2$ ms Latency)
* **Closed-Loop Actuation:** Mechanical Speed Governor (locks speed to 50 km/h upon intrusion confirmation), Seatbelt Pre-Tensioner, In-Cabin Audio Telematics Warning.
* **Benchmark Accuracy:** **98.6%** over 12,000 CAN packets.
